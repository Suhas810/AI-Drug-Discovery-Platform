## 📖 Overview

Drug discovery is a complex and time-consuming process that traditionally requires years of research and significant financial investment.

The **AI Drug Discovery Platform** leverages Artificial Intelligence and Machine Learning to assist researchers by analyzing molecular datasets, predicting drug properties, and supporting faster decision-making during early-stage drug development.

This project demonstrates how AI can be integrated into healthcare and pharmaceutical research to improve efficiency and reduce development time.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Suhas810/AI-Drug-Discovery-Platform.git
```

Move into the project

```bash
cd AI-Drug-Discovery-Platform
```

Create virtual environment

```bash
python -m venv venv
```

Activate environment

Windows

```bash
venv\Scripts\activate
```

Linux/Mac

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```
